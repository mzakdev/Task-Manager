# Task Manager

A clean, minimal task management application built with **React** and **Tailwind CSS**, designed to help users organize tasks and stay focused.

## ✨ Features

- **Add Tasks** — Create new tasks with a title and description.
- **Complete Tasks** — Mark tasks as completed using checkboxes.
- **Delete Tasks** — Remove tasks you no longer need.
- **Filter Tasks** — View all tasks, active tasks, or completed tasks.
- **Responsive Design** — A simple interface designed for different screen sizes.
- **Minimal UI** — A dark theme with pistachio-green accents and ivory text.

## 🛠️ Tech Stack

- **React** — Component-based UI development.
- **Vite** — Development server and build tool.
- **Tailwind CSS** — Utility-first styling.
- **Lucide React** — Icons.
- **JavaScript (ES6+)** — Application logic.

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/react-task-manager.git
   ```

2. Navigate to the project directory:

   ```bash
   cd react-task-manager
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173`.
